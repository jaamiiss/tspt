Why TSPT?

Many laptops on Linux do not expose firmware battery charge thresholds via ACPI. TSPT automates a Tapo smart plug directly from your desktop panel in ~25–35 MB of RAM instead of multi-gigabyte webview wrappers.

Native Top-Bar Applet

Uses GTK 3 and AyatanaAppIndicator3 with clean monochrome symbolic SVGs that sit naturally beside Wi-Fi and sound icons.

Modern TPAP Protocol

Connects directly over HTTP/TPAP for Tapo P105 v1.4.0+ firmware where legacy KLAP libraries fail with HTTP 403.

15-Min Hardware Failsafe

Before cutting charger power, an onboard 15-minute ON countdown is verified on the plug itself, so if your laptop sleeps or loses Wi-Fi, power returns automatically.

Using the Application

Click the plug icon in your Linux panel to view live telemetry, toggle power manually, or adjust Auto-Charge Guard thresholds on the fly:

  • Battery & Plug Telemetry Displays live sysfs percentage, charging state, wattage, and whether the 15-minute onboard failsafe is active.
  • Turn On / Turn Off / Refresh Status Manually switch relay power (with automatic failsafe arming when turning off) or poll live LAN status.
  • Auto-Charge & Threshold Presets Pause or resume automatic switching in one click, or pick presets (20%–80%, 25%–80%, 20%–85%, 30%–75%).
  • Edit Config, Logs & Built-In Guide Opens config.json, history.log, or the bundled guide in your desktop text editor. Saved config edits hot-reload automatically.

Editing Configuration & Plug Info

Run tspt init for an interactive wizard (sets plug IP, saves private chmod 600 credentials, and auto-probes the plug MAC), or click Edit Config in the tray menu to edit ~/.config/tspt/config.json directly.

Configuration Reference (~/.config/tspt/config.json)
Field Default Purpose
plug.ip "" Local LAN IPv4 of your Tapo smart plug (check router DHCP list or Tapo app → Device Info; reserve a static DHCP lease).
plug.mac "" 12-hex hardware MAC lock (AA:BB:CC:DD:EE:FF). Required for Auto-Charge so TSPT refuses to toggle another device if IPs change.
plug.model "P105" Expected smart plug model string (leave empty "" to skip model check).
plug.protocol "tpap" "tpap" for Tapo P105 firmware 1.4.0+, or "auto" for older Kasa/Tapo devices.
battery.path "auto" Auto-detects BAT0/BAT1 in /sys/class/power_supply, or set an explicit path.
battery.serial "" Optional battery serial lock; leave empty to accept any present laptop battery.
auto_charge.enabled false Enables background charge-threshold control once charger_only_confirmed is true.
auto_charge.turn_on / turn_off 20 / 80 Hysteresis bounds (10 <= turn_on < turn_off <= 95). Turns ON at/below turn_on% and OFF at/above turn_off%.
ui.show_label false Show live text next to the top-bar icon using ui.label_format (supports {battery}, {status}, {plug}).
ui.editor "" Optional editor command (e.g. "subl" or "code"); defaults to your desktop's text/plain editor.
How do I change the smart plug IP or replace my plug?

Run tspt init in a terminal to enter the new IP and automatically probe/update the verified plug.mac, or click Edit Config in the top-bar menu and update plug.ip and plug.mac directly.

Where are my Tapo email and password stored?

Credentials live separately in ~/.config/tspt/credentials.json ({"tapo_email": "...", "tapo_password": "..."}) and must have private chmod 600 permissions. You can also supply TAPO_EMAIL and TAPO_PASSWORD environment variables instead.

Can I control TSPT from scripts or a terminal?

Yes. Use tspt status (or --json), tspt on, tspt off, and tspt check --apply from any terminal.
